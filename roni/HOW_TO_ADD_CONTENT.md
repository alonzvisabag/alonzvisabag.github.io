# איך מוסיפים תוכן

## הדרך הפשוטה — שולחים לחברים לינק

הכתובת ששולחים לחברים: **https://alonzvisabag.github.io/roni/contribute.html**

בלינק הזה, כל חבר:
- לא צריך סיסמה בכלל.
- רואה רק את רשימת "הרגעים" (המשפטים "ברגע ש...") — לא רואה שום תוכן שכבר הועלה על ידי אחרים.
- יכול לבחור רגע קיים ולהוסיף לו הקלטה קולית (מוקלטת ישירות בדפדפן), תמונה/סרטון מצורף, או מכתב כתוב.
- יכול גם ליצור רגע חדש לגמרי משלו (בוחר לאיזה חלק באתר זה שייך, איזה סוג תוכן, וכותב מתי כדאי לרוני לפתוח את זה).
- אפשר לכמה חברים שונים לבחור באותו רגע בדיוק — כל התרומות נשמרות זו לצד זו, ורוני רואה את כולן כשהיא פותחת את הכמוסה.

ברגע שחבר שולח, זה נשמר ישירות לאתר החי תוך כמה שניות (דרך שרת קטן ב-Cloudflare שמחזיק את ההרשאה לכתוב ל-GitHub — אף חבר לא רואה או צריך שום סיסמה/טוקן).

## הדרך הידנית — לערוך בעצמכם דרך GitHub

אם אתם (לא חבר) רוצים להוסיף/לערוך תוכן ישירות, בלי דרך עמוד ה-contribute:

כל התוכן חי בקובץ אחד — `roni/content.json`. כל קבצי המדיה חיים בתיקייה `roni/media/`, בלי תיקיות משנה.

כל כמוסה נראית כך:

```json
{
  "id": "a1-1",
  "trigger": "ברגע ש...",
  "type": "letter",
  "desc": "הערה לעצמכם — לא מוצג לרוני",
  "items": [
    { "from": "דנה", "text": "רוני יקרה...\n\nשורה שנייה", "media": null },
    { "from": null, "text": null, "media": "a1-1-1234567890.m4a" }
  ]
}
```

- `items` הוא מערך — כל תרומה (מכל חבר) היא איבר נפרד בתוכו. אפשר להוסיף איברים ידנית באותה צורה.
- `from` (רשות) — שם התורם/ת, מוצג לרוני מעל התוכן.
- `text` ו/או `media` — אפשר אחד מהם, או שניהם באותו איבר.
- ערכים אפשריים ל־`type`: `letter` (מכתב), `audio` (הקלטה), `video` (וידאו), `photo` (תמונה), `playlist` (פלייליסט), `idea` (רעיון/הוראה).

כדי להעלות קובץ מדיה ידנית: ב-github.com, נווטו ל-`roni/media`, **Add file → Upload files**, תנו שם קובץ באנגלית בלי רווחים, **Commit changes**. אחר כך ערכו את `content.json` (סמל העיפרון) והוסיפו איבר ל-`items` עם שם הקובץ המדויק.

שימו לב לפסיקים (`,`) — זה JSON, רגיש לתחביר. אם משהו נשבר, אפשר ללחוץ "History" על הקובץ בגיטהאב ולחזור לגרסה קודמת.

## שינוי הסיסמה או כותרות האתר של רוני

בתוך `content.json`, תחת `"site"`:
- `"password"` — הסיסמה שרוני מזינה בכניסה ל-`roni/index.html` (עמוד ה-contribute אין לו סיסמה בכלל).
- `"title"` / `"subtitle"` — הכותרת והפתיח שמופיעים לרוני.
- `"gatePhoto"` / `"revealPhoto"` — שמות קבצי התמונות סביב מסך הסיסמה (לפני/אחרי הזנת הסיסמה הנכונה).

## הערה על אבטחה

עמוד רוני (`index.html`) מוגן בסיסמה בסיסית בצד הלקוח — מספיק כדי שאף אחד לא ייתקל בו במקרה, לא הגנה אמיתית. עמוד ה-contribute פתוח לגמרי (בכוונה, כדי שחברים יוכלו לגשת בקלות) — אל תשתפו את הלינק שלו בפומבי, רק ישירות עם חברים. הטוקן שמאפשר כתיבה ל-GitHub יושב רק בתוך השרת ב-Cloudflare (secret, לא בקוד הציבורי), כך שאף חבר לא יכול לראות אותו.
