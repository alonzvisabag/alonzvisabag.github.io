# איך מוסיפים תוכן מהטלפון (בלי מחשב)

הכתובת של האתר: `https://alonzvisabag.github.io/roni/`
הסיסמה של רוני מוגדרת בקובץ `content.json`, שדה `"password"`.

כל התוכן חי בקובץ אחד — `roni/content.json`. כל קבצי המדיה (הקלטות/סרטונים/תמונות) חיים בתיקייה `roni/media/`, בלי תיקיות משנה.

## שלב 1 — להעלות קובץ מדיה (הקלטה/סרטון/תמונה)

1. מהטלפון, פתחי דפדפן (כרום/ספארי) וכנסי ל־github.com והתחברי עם המשתמש `alonzvisabag`.
2. נווטי לתיקייה: `alonzvisabag.github.io` → `roni` → `media`.
3. לחצי על **Add file → Upload files**.
4. בחרי את הקובץ מהגלריה/מהמצלמה של הטלפון והעלי.
5. תני שם קובץ באנגלית, בלי רווחים ובלי עברית — למשל `a1-1.m4a` או `night-one.mp4`. הכי נוח לקרוא לקובץ בדיוק כמו ה־`id` של הכמוסה שהוא שייך אליה, כדי שיהיה קל לזהות.
6. בתחתית העמוד לחצי **Commit changes**.

## שלב 2 — לקשר את הקובץ / להוסיף טקסט, בתוך content.json

1. נווטי ל־`roni/content.json`.
2. לחצי על סמל העיפרון (Edit) בפינה הימנית העליונה.
3. מצאי את הכמוסה המתאימה לפי ה־`trigger` (המשפט "ברגע ש...").
4. אם העלית קובץ מדיה: מלאי את השדה `"media"` בשם הקובץ המדויק שהעלית, לדוגמה:
   ```
   "media": "a1-1.m4a"
   ```
5. אם זה מכתב/טקסט (בלי קובץ): מלאי את השדה `"text"` בטקסט המלא. אפשר שורות חדשות, הן יישמרו.
   ```
   "text": "רוני יקרה,\n\nהיום את נכנסת לדירה החדשה שלך..."
   ```
6. אפשר גם וגם (טקסט + מדיה) באותה כמוסה — שניהם יוצגו.
7. גללי למטה ולחצי **Commit changes**.

זהו. אחרי כמה שניות (או דקה) GitHub Pages יעדכן את האתר החי אוטומטית.

## הוספת כמוסה חדשה לגמרי

כל כמוסה היא בלוק כזה בתוך `content.json`, בתוך `"capsules"` של אחת מהמערכות (`act1`/`act2`/`act3`) או בתוך `"extra"`:

```json
{
  "id": "מזהה-ייחודי-כלשהו",
  "trigger": "ברגע ש...",
  "type": "letter",
  "desc": "הערה לעצמכם על מה רוצים שיהיה כאן — לא מוצג לרוני",
  "text": null,
  "media": null
}
```

ערכים אפשריים ל־`type` (קובעים אייקון ותווית): `letter` (מכתב), `audio` (הקלטה), `video` (וידאו), `photo` (תמונה), `playlist` (פלייליסט), `idea` (רעיון/הוראה).

שימי לב לפסיק (`,`) בסוף כל שורה חוץ מהאחרונה בבלוק — זה JSON, ורגיש לתחביר. אם משהו נשבר, אפשר תמיד ללחוץ "History" בגיטהאב על הקובץ ולחזור לגרסה קודמת.

## שינוי הסיסמה או כותרות האתר

גם אלה בתוך `content.json`, תחת `"site"`:
- `"password"` — הסיסמה שרוני מזינה.
- `"title"` / `"subtitle"` — הכותרת והפתיח שמופיעים לרוני.

## הערה על אבטחה

זו הגנת סיסמה בסיסית בצד הלקוח (JavaScript) — מספיקה כדי שאף אחד לא ייתקל באתר במקרה, אבל לא הגנה אמיתית מפני מישהו טכני שממש מנסה. אל תשימו שם תוכן שאסור שיזלוג בשום מצב.
